# Hospital Readmission Prediction within 30 Days

Data Mining course project.

## Main task
Classification: Predict 30-day hospital readmission.

## Secondary task
Association rule mining.

## Technologies
Python, JupyterLab, PostgreSQL, Apache Superset.

## Data source
UCI Diabetes 130-US Hospitals (1999–2008).

## Reproducibility
See requirements.txt, notebooks/, sql/, and scripts/.

Raw patient-level data, credentials and local database backups
are intentionally excluded from this repository.
